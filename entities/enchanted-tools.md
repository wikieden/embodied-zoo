# Enchanted Tools

2021 年成立于法国巴黎。团队来自 Aldebaran / SoftBank Robotics（Pepper/Nao 原班人马）。核心产品 Miroki，定位**服务/社交场景**。

## Miroki 特点

- 身高 120-130cm / 体重 30-40kg / **轮式底座**（非双足）
- 头部表情显示屏，可呈现丰富情感
- 轻量级、软体材料包裹，适合与老人/儿童近距离互动
- 续航 6-8h，静音运行

## AI 架构

- **对话与情感交互**：LLM + 情感识别 + 语音合成
- **轮式 SLAM**：2D/3D 语义地图，电梯/门禁集成
- **操作有限**：主要递送小物品（药品、文件、水杯），预定义抓取策略

## 商业模式

- 目标欧洲医疗/康养市场
- 与医院、养老机构试点合作
- 吸取 Pepper 商业化失败教训

## 关系

- 与 [[apptronik]]、[[genesis-ai]] 类似采用"硬件+合作 AI"模式
- 与 [[figure-ai]]、[[1x-technologies]]、[[tesla-optimus]] 目标市场不同
